DEE is a web application designed for the internal management of productions and operations, bringing together information about projects, schedules, events, teams, budgets, and an effects catalog in one centralized platform. It streamlines the monitoring of ongoing productions by providing an operational dashboard, schedule management, production tracking, and a technical library containing references, suppliers, equipment, and media associated with the effects used across different projects.

Built with Next.js, React, and TypeScript, the system features a modern, responsive interface styled with Tailwind CSS. For data storage and management, DEE uses PostgreSQL as its relational database and Prisma ORM as its data access layer, structuring entities such as users, productions, tasks, internal events, documents, budgets, and effects. The application also includes user authentication, image uploads, and Google Calendar integration, allowing external events to be synchronized directly with the dashboard's schedule.

DEE é uma aplicação web voltada à gestão interna de produções e operações, reunindo em um só lugar informações sobre projetos, cronogramas, eventos, equipes, orçamentos e um catálogo de efeitos. A plataforma centraliza o acompanhamento das produções em andamento, permitindo visualizar o painel operacional, organizar a agenda, consultar produções e administrar um acervo técnico de referências, fornecedores, equipamentos e mídias associadas aos efeitos usados nos projetos.

Desenvolvido com Next.js, React e TypeScript, o sistema possui uma interface moderna e responsiva construída com Tailwind CSS. Para armazenamento e gerenciamento dos dados, o DEE utiliza PostgreSQL como banco de dados relacional e Prisma ORM como camada de acesso, estruturando entidades como usuários, produções, tarefas, eventos internos, documentos, orçamento e efeitos. A aplicação também conta com autenticação de usuários, upload de imagens e integração com Google Calendar, permitindo sincronizar eventos externos diretamente na agenda do painel.
